Container

    Neuer Container

    Erweitert

    Fordert Zugriff auf alle https-Seiten an. Nötig, wenn der Login von einer Domain außerhalb von Microsoft zurück zu login.microsoftonline.com springt.

    Hilft, wenn eine Seite in einem Container dauerhaft die falsche Sitzung zeigt.

    Sicherung ● noch keine Sicherung

    Container werden in Chrome gespeichert und bleiben bei Updates erhalten. Wird die Erweiterung entfernt, sind sie weg – dafür gibt es diese Sicherungsdatei.

    Achtung: Die Datei enthält dann Zugangstoken. Nur sicher aufbewahren, nicht weitergeben.

    Diagnose ● Aufzeichnung läuft

    Zeichnet den Anmeldeablauf auf (Adressen, Weiterleitungen, Cookie-Namen, Tenantry-Schritte). Cookie-Werte, Token und Formularinhalte werden nicht gespeichert. Ablauf: Starten → Fehler nachstellen → Stoppen → Exportieren.
